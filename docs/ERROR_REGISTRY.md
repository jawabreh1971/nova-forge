# Atlas Error Registry (v1)

## Format
- `ATLAS-1xxx` Input/Client
- `ATLAS-2xxx` External dependencies
- `ATLAS-3xxx` Auth/Permissions
- `ATLAS-4xxx` Data/Storage
- `ATLAS-5xxx` Internal/Unexpected

## Codes
- ATLAS-1001: INVALID_INPUT
- ATLAS-1002: MISSING_FIELD
- ATLAS-2001: EXTERNAL_TIMEOUT
- ATLAS-2002: EXTERNAL_BAD_RESPONSE
- ATLAS-3001: UNAUTHORIZED
- ATLAS-3002: FORBIDDEN
- ATLAS-5001: INTERNAL_ERROR
